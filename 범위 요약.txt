자료구조: 자료를 효율적으로 관리하는 방법
-단순 자료구조: 정수, 실수, 문자, 문자열
-선형 자료구조: 데이터를 한 줄로 순차적으로 표현한 형태 (리스트, 스택, 큐)
-비선형 자료구조: 하나의 데이터 뒤에 여러 개가 이어지는 형태 (트리, 그래프)
-파일 자료구조: 순차 파일, 색인 파일, 직진 파일

파이썬 제외

선형 리스트: 데이터를 일정한 순서로 나열
배열(index) 활용
삽입, 삭제를 할때 데이터량이 많을 수록 처리에 시간이 많이 소모
데이터 삽입/삭제하는 방법

단순 연결 리스트: 떨어진 곳에 위치한 데이터를 화살표로 연결
노드 구조
노드: 데이터, 링크로 구성된 항목
데이터 삽입/삭제하는 방법 (순서 강조)
노드 생성: 클래스 문법 사용해 데이터형 정의
노드 연결
head: 첫 번째 노드를 가리킴
current: 현재 처리중인 노드를 가리킴
pre: 현재 처리중인 노드의 바로 앞 노드를 가리킴

원형 연결 리스트: 시작 위치와 다음 위치가 계속 이어진 후 마지막에 다시 시작으로 돌아오는 원과 같은 형태 (단순 연결 리스트와 같은 구조지만 마지막 노드가 첫 번째 노드를 가리키는 링크를 가진다)
head, current, pre 모두 단순 연결 리스트와 역할이 같음
배열에 저장된 데이터 입력 과정
첫 번째 노드 작성 시 스스로를 가리키게 작성
새 노드 작성 시 첫 노드가 자신을 가리키게 작성, 자신은 첫 노드 가리키게 작성
